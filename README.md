# Rock Paper Scissors Game

A beginner-friendly Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Features
- Play against the computer
- Random computer choices
- Score tracking for both sides
- Round result and selected moves
- Reset score button
- Responsive layout for mobile and desktop

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Publish with GitHub Pages
1. Push `index.html`, `style.css`, and `script.js` to your GitHub repository.
2. Open **Settings → Pages**.
3. Under the build/deployment section, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site.

Repository name: `rock-paper-scissors-game`
